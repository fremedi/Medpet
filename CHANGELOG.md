# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
y este proyecto sigue [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-dev] - 2026-05-11

### Agregado
- ✨ Asistente IA veterinario usando GPT-4o
- ✨ Gestión de citas con flujo conversacional
- ✨ Integración con WhatsApp Cloud API
- ✨ Menú interactivo con botones de respuesta rápida
- ✨ Envío de ubicación e información de contacto
- ✨ Almacenamiento automático de citas en Google Sheets
- ✨ Webhook para recepción de mensajes
- ✨ Detección inteligente de saludos
- ✨ Normalización de números telefónicos argentinos
- ✨ Gestión de estado conversacional por usuario
- ✨ Manejo de múltiples usuarios simultáneamente

### Cambios
- 📝 Documentación completa (README, CONTRIBUTING, CHANGELOG)
- 🏗️ Arquitectura MVC implementada
- 🔒 Configuración segura con variables de entorno

### Notas
- Este es un lanzamiento de desarrollo (pre-release)
- Se espera que la API sea estable en v0.2.0
